# Повар 🍳

Помощник в готовке: **iOS‑приложение** (SwiftUI) и **сайт для телефона и компьютера** (`web/`).

## Сайт (`web/index.html`)

Один HTML‑файл без сборки и зависимостей — откройте в браузере или выложите на любой хостинг (GitHub Pages, Netlify). Работает на телефоне и компьютере.

- **208 блюд** в 11 разделах и **149 продуктов** в справочнике.
- **Умный поиск**: по названию и продуктам, понимает опечатки («сырнеки» → сырники), разговорные названия («картошка», «макарошки»), английскую раскладку («rehbwf» → курица) и слова‑фильтры («быстро», «без мяса», «в духовке»). Показывает, что именно он понял.
- Разделы, фильтры (до 30 минут, из моих продуктов, без мяса, до 5 продуктов, духовка, без плиты) и сортировка.
- Персоны → пересчёт граммовки; сила огня по шкале конфорки 1–9 и духовка в °C; время шага и «время у плиты»; посуда.
- **Избранное**, «Недавно смотрели», отметки выполненных шагов, ссылка на рецепт.
- **Мои продукты**: частые продукты в один клик, поиск с опечатками (Enter отмечает первый), распознавание по фото через Claude, замены недостающих продуктов.
- **Список покупок**: кнопка «В список покупок» в рецепте, «Что докупить в первую очередь» на вкладке идей; купленное переезжает в «У меня есть» одним нажатием.
- «Что приготовить»: готово сейчас / не хватает 1–2 продуктов, «Совет повара» и «Спросить шефа» (Claude).
- Таймеры: несколько сразу, запуск из шага, звук и вибрация, шпаргалка по варке.
- Режим готовки: крупный шаг, предпросмотр следующего, экран не гаснет, стрелки ←/→ на клавиатуре; `/` — фокус в поиск.

Данные хранятся в браузере (localStorage). Для фото и советов шефа на своём хостинге нужен ключ Claude API — вводится на вкладке «Продукты» и хранится только в браузере.

Исходники — `web/src/` (`data.js` — рецепты, продукты и синонимы; `search.js` — поиск; `app.js`; `style.css`); после правок выполните `web/src/build.sh`.

## Возможности

| Что | Где |
|---|---|
| **Количество персон** — степпер 1–20, вся граммовка пересчитывается автоматически | карточка рецепта |
| **Граммовка и ингредиенты** — граммы/мл/шт/ложки, для штучных продуктов «≈ N г», отметка ✅ если продукт есть дома | карточка рецепта |
| **Какой огонь** — индикатор 🔥 (слабый / средний / выше среднего / сильный / духовка °C) и подсказка для конфорки «4–5 из 9» | каждый шаг |
| **Сколько готовить** — время каждого шага и общее время блюда | каждый шаг, список |
| **Какая посуда нужна** — список посуды для каждого рецепта | карточка рецепта |
| **Распознавание продуктов по фото** — камера или галерея → список найденных продуктов → добавить в «Мои продукты» | вкладка «Продукты» |
| **Что приготовить из того, что есть** — подбор рецептов, «чего не хватает», замены продуктов и «Совет повара» | вкладка «Что приготовить» |
| **Таймер готовки** — несколько таймеров одновременно, запуск прямо из шага рецепта, пауза, +1 мин, уведомление и звук, шпаргалка (яйца, рис, гречка…) | вкладка «Таймеры», режим готовки |
| **Режим готовки** — пошаговый экран крупным шрифтом, экран не гаснет | кнопка «Начать готовку» |

В приложении 14 рецептов: омлет, блины, сырники, борщ, куриный суп, жареная картошка, паста, макароны по‑флотски, гречка с грибами, куриное филе, плов, запечённая рыба, овощной салат, шарлотка.

## Распознавание фото — два режима

Переключается в настройках (⚙️ на вкладке «Продукты»):

1. **На устройстве (Vision)** — по умолчанию. Бесплатно, офлайн, через `VNClassifyImageRequest`. Хорошо узнаёт отдельные продукты (яйца, помидоры, яблоки, морковь), хуже — продукты в упаковках. *Работает только на реальном iPhone, в симуляторе Vision‑классификатор недоступен.*
2. **Claude AI** — точнее: узнаёт продукты в холодильнике и по этикеткам. Нужен API‑ключ с [console.anthropic.com](https://console.anthropic.com). Ключ хранится в Связке ключей iOS. Модель по умолчанию — `claude-opus-5-5` (можно поменять в настройках).

## Запуск

1. macOS + **Xcode 16** или новее.
2. Откройте `Povar.xcodeproj`.
3. Target **Povar → Signing & Capabilities** → выберите свою команду (подойдёт бесплатный Apple ID).
4. Подключите iPhone и нажмите ▶︎ Run.

## Структура

```
Povar/
├── App/PovarApp.swift            точка входа, уведомления
├── Models/Models.swift           огонь, единицы, посуда, рецепт, шаги
├── Data/
│   ├── IngredientCatalog.swift   справочник продуктов (+ метки для Vision)
│   └── RecipeBook.swift          рецепты
├── Services/
│   ├── PantryStore.swift         «мои продукты» (сохраняются)
│   ├── SuggestionEngine.swift    подбор рецептов и советы
│   ├── IngredientRecognizer.swift распознавание фото (Vision / Claude)
│   ├── TimerManager.swift        таймеры + локальные уведомления
│   └── Keychain.swift
└── Views/                        экраны SwiftUI
```

Добавить рецепт — допишите `Recipe(...)` в `RecipeBook.swift`; новый продукт — `IngredientInfo(...)` в `IngredientCatalog.swift`.
